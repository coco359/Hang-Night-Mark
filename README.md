# 私人笔记库

这是一个基于GitHub Pages的私人笔记库，用于存放个人的社会观察、焦虑思考、人生感悟和创作素材。

## 目录结构

```
├── index.html          # 首页
├── tags.html           # 标签归档页
├── 01_自我焦虑与和解/    # 存放自我焦虑相关笔记
├── 02_社会现象观察/    # 存放社会现象观察笔记
├── 03_创作素材库存/    # 存放创作素材
└── README.md           # 说明文件
```

## 使用方法

1. **注册GitHub账号**：访问 https://github.com 注册账号
2. **创建仓库**：创建一个名为 `用户名.github.io` 的仓库，设置为私有
3. **上传文件**：将本项目的所有文件上传到仓库
4. **启用GitHub Pages**：在仓库设置中启用GitHub Pages，选择main分支
5. **访问网站**：通过 `https://用户名.github.io` 访问你的私人笔记库

## 如何添加笔记

1. 在对应的文件夹中创建Markdown文件（.md后缀）
2. 使用统一的模板格式编写笔记
3. 上传到GitHub仓库
4. 等待几分钟，网站会自动更新

## 如何修改内容

1. 在GitHub网页端直接编辑文件
2. 或在本地修改后上传

## 隐私设置

- 确保仓库设置为私有
- 只有你能访问网站（需要登录GitHub账号）

## 搜索功能

- 在首页的搜索框中输入关键词，可搜索笔记内容

## 标签功能

- 在笔记中添加标签，可在tags.html页面按标签浏览
